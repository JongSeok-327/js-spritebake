**내 영상으로 만드는 투명 스프라이트 시트.**

**내 영상 없이 먼저 사용해 보기:** 앱을 실행하고 **샘플 영상으로 시작**을 누르면, 포함된 [2초짜리 MP4](dist/samples/walk-demo.mp4)를 불러와 12프레임으로 추출하고 바로 재생합니다. 이 프로젝트를 위해 직접 그린 도형 캐릭터이며 샘플과 데모에도 MIT 라이선스를 적용합니다. [샘플 제작 정보](docs/SAMPLES.md) · [출력 시트 화면](docs/assets/sheet-en.png).

앱 화면과 설명서를 모두 **영어·한국어·일본어**로 제공합니다. 오른쪽 위에서 언어를 바꿔도 현재 영상과 프레임 편집은 유지됩니다. 처음에는 브라우저 언어를 따르며 지원 언어가 없으면 영어로 표시합니다. 로컬 주소 뒤에 `?lang=en`, `?lang=ko`, `?lang=ja`를 붙여 해당 언어로 열 수도 있습니다. 번역 API·쿠키·localStorage는 사용하지 않습니다.

## 만든 이유

캐릭터 영상을 스프라이트로 만드는 작업을 하다 보니, 이런 도구가 있으면 편하겠어서 만들었습니다. 직접 쓰면서 조금씩 다듬은 개인 작업 도구인데, 비슷한 작업을 하는 분들에게도 도움이 될까 해서 공유합니다.

## 주요 기능

- 내 컴퓨터의 영상을 열고 사용할 구간과 프레임 수 선택
- 단색 배경 제거, 가장자리 부드러움과 배경색 번짐 조절
- 동작 전체에 같은 잘라내기 영역과 배율 적용, 프레임별 위치 보정
- 애니메이션·출력 시트·개별 프레임·이전 자세 겹쳐보기
- 인접 중복 후보 비교·제외·되돌리기, 제외한 후보의 재생 시간 유지
- 투명 PNG 시트 또는 개별 PNG·재생 정보·설정 JSON이 들어 있는 ZIP 저장

**v1.1.0 · MIT · 실행용 패키지 설치 없음 · API 키 불필요**

처음에는 빈 작업 화면으로 시작하고, 샘플은 버튼을 눌렀을 때만 불러옵니다. 개인 작업 영상은 포함하지 않습니다.

## 준비사항

| 필요한 것 | 설명 |
| --- | --- |
| Python | [공식 사이트](https://www.python.org/downloads/)에서 설치한 **3.11 이상**. 아래 명령으로 버전을 확인하세요. |
| 브라우저 | 최신 데스크톱 **Chrome 또는 Edge** 권장. 영상 코덱 지원은 브라우저와 OS에 따라 다르며 MP4/H.264부터 시도하기 좋습니다. |
| 컴퓨터 | Windows 또는 macOS. 영상과 프레임을 처리할 메모리가 필요합니다. 처음에는 512–1024px, 12–24프레임으로 시작하세요. |

Python은 화면 파일만 제공하며 영상은 브라우저에서 처리합니다. **사용할 때 FFmpeg, Node.js, npm, Git, 별도 GPU 프로그램, 유료 계정이나 영상 생성 서비스가 필요하지 않습니다.** 프로젝트 다운로드와 Python·브라우저 설치를 마치면 인터넷 연결 없이 실행할 수 있습니다.

실제 검증 환경은 Windows·Python 3.11·Chrome입니다. macOS는 공통 Python/브라우저 기능을 사용하도록 실행 파일과 설명을 준비했지만, **실제 MacBook에서의 검증은 아직 하지 못했습니다.** Safari·Firefox·스마트폰은 현재 검증 대상이 아닙니다.

## Windows에서 실행

1. Python 3.11 이상을 설치합니다. `py` 런처 또는 `python` 명령을 사용할 수 있도록 설치하고, 설치 후 터미널을 다시 여세요.
2. 저장소 ZIP 또는 릴리스 ZIP을 다운로드한 뒤 **전체 폴더를 압축 해제**합니다. ZIP 내부에서 바로 실행하지 마세요.
3. **`start.cmd`를 더블클릭**합니다. `py -3`를 먼저 찾고, 없으면 `python`을 사용해 기본 브라우저를 엽니다.
4. 작업하는 동안 명령 창을 열어 둡니다. 종료하려면 해당 창에서 **Ctrl+C**를 누르세요.

압축을 푼 폴더에서 PowerShell로 실행할 수도 있습니다.

```powershell
py -3 --version
py -3 server.py
```

`py`가 없고 `python` 명령을 사용할 수 있다면:

```powershell
python --version
python server.py
```

기본 브라우저에서 영상이 열리지 않으면, 출력된 로컬 주소를 Chrome이나 Edge에 붙여 넣으세요.

## macOS / MacBook에서 실행

1. [python.org](https://www.python.org/downloads/)에서 Python 3.11 이상을 설치합니다. `python3 --version`으로 버전을 확인하세요.
2. 다운로드한 ZIP 전체를 압축 해제합니다.
3. 프로젝트 폴더에서 터미널을 열고 실행합니다.

```sh
python3 --version
python3 server.py
```

작업하는 동안 터미널을 열어 두고, 종료하려면 **Control+C**를 누르세요. 실행 스크립트는 Intel·Apple Silicon 전용 바이너리에 의존하지 않으며, 영상 디코딩은 브라우저가 담당합니다.

더블클릭으로 실행하려면 같은 폴더에서 한 번 실행 권한을 부여합니다.

```sh
chmod +x start.command
./start.command
```

이후 Finder에서 `start.command`를 더블클릭할 수 있습니다. macOS가 다운로드한 스크립트를 차단하면 내용을 확인하고 위의 터미널 명령으로 실행하세요. 시스템 보안 기능을 끌 필요는 없습니다. Homebrew도 필수가 아닙니다.

## 접속 주소와 실행 옵션

기본 주소는 **`http://127.0.0.1:8765`**입니다. 사용 중이면 다음 19개 포트 중 가능한 것을 고르고 실제 주소를 표시합니다. `dist/index.html`을 직접 더블클릭하면 모듈·워커가 제대로 동작하지 않을 수 있으니 출력된 주소로 접속하세요.

```sh
# macOS 기준. Windows에서는 python3 대신 py -3 또는 python 사용
python3 server.py --no-browser
python3 server.py --port 8900
```

## 사용 순서

1. **영상 파일 열기**를 누르거나 파일을 끌어 놓습니다.
2. **시작 / 끝**, **추출 프레임 수**를 정합니다. 기본은 첫 1초·12프레임입니다. 걷기는 한 주기에 맞춰 구간을 잡아 보세요.
3. **프레임 추출**을 누릅니다. 끝 시각은 포함하지 않는 균등 추출입니다.
4. 배경색을 선택하거나 **원본에서 색 찍기**를 사용합니다. 제거 범위·가장자리·번짐을 조절하고 밝고 어두운 배경에서 결과를 확인합니다.
5. 프레임을 선택해 원본 위치와 비교합니다. 이전/다음, 이전 자세 겹치기, 포함 체크, X/Y 위치 보정으로 정리합니다. **출력 시트**에서 저장 배치를 볼 수 있습니다.
6. 중복 후보 번호를 누르면 두 자세가 번갈아 표시됩니다. **후보 제외**로 적용하고 **되돌리기**로 복원합니다. 적용 내역이 남으며 체크나 위치를 바꾸면 후보를 다시 검사합니다.
7. **PNG 시트** 또는 **전체 ZIP 저장**으로 결과를 다운로드합니다. 나중에 이어서 작업하려면 탭을 닫기 전에 설정도 저장하세요.

**설정 초기화**는 현재 영상을 유지하면서 설정·선택/제외·위치·합쳐진 시간을 기본값으로 돌리고 첫 1초를 다시 추출합니다.

원본은 고정 카메라, 전신, 무기까지 들어오는 여백, 캐릭터 색과 겹치지 않는 균일한 단색 배경이 좋습니다. 게임 코드로 이동을 제어한다면 제자리 걷기가 다루기 편합니다.

## 저장 파일과 재생 시간

| 파일 | 내용 |
| --- | --- |
| `*-sheet.png` | 투명 RGBA 스프라이트 시트 |
| `frames/001.png` 등 | ZIP에 포함되는 개별 투명 프레임 |
| `*.json` | 시트 좌표, 원본 시각, 위치 보정, 기준점, 프레임별 `durationMs` |
| `*-settings.json` | 처리 설정과 프레임 편집 정보. 영상은 포함하지 않음 |

중복 후보는 현재 포함된 순서에서 이웃한 프레임만 비교합니다. 배경을 제외한 전체 캐릭터와 하체의 차이가 모두 기준 이하여야 후보가 됩니다. 자동 동작 이해나 걷기 주기 탐지가 아닌 보조 판단이므로 비교 후 적용하세요.

**중복을 합친 결과의 속도를 유지하려면 게임에서도 각 프레임의 `durationMs`를 사용해야 합니다.** PNG만으로는 서로 다른 재생 시간을 저장할 수 없습니다. 직접 체크를 해제하면 그 시간도 빠지고, 중복 후보 제외는 해당 시간을 앞의 남긴 프레임에 합칩니다. **모두 포함**은 모든 프레임과 기본 시간을 복원합니다.

기본 기준점 `(0.5, 0.9)`는 출력 칸 기준이며 발을 자동 검출한 위치가 아닙니다. X/Y는 출력 픽셀 단위입니다. 미리보기의 기준선·번호·겹치기는 저장 PNG에 들어가지 않습니다. 이어서 작업하려면 같은 영상을 열고 설정 JSON을 불러온 뒤 다시 추출하세요. 새 파일은 `js-spritebake` / `js-spritebake-preset` 식별자를 쓰며, 예전 시제품의 설정도 계속 불러올 수 있습니다.

## 개인정보와 로컬 보안

- 영상은 브라우저의 File/Blob 기능으로 읽고 메모리에서 처리합니다. **영상 업로드 API, 클라우드 처리, 계정, 분석 도구, 앱 쿠키, CDN, 외부 폰트 요청이 없습니다.**
- 서버는 **`127.0.0.1`에만 연결**하며 LAN 전체에 열지 않습니다. `dist/`의 앱 파일만 제공하고, 다른 Host/Origin·파일 쓰기 요청·디렉터리 목록·앱 폴더 밖으로 연결되는 경로를 차단하며 브라우저 보안 헤더를 보냅니다.
- 앱과 워커를 읽기 위한 로컬 HTTP 요청은 발생합니다. 다운로드는 사용자가 요청할 때 이루어집니다. 결과 JSON에는 원본 파일명과 처리 정보가 들어가니 공유 전에 확인하세요.
- 자동 저장하지 않습니다. 새로고침하거나 탭을 닫으면 메모리의 작업이 사라지므로 설정과 결과를 먼저 저장하세요. 브라우저 확장 기능·악성 프로그램·브라우저 자체의 통신은 이 앱이 통제하지 못합니다.

**로컬 실행이 모든 위험이 없다는 뜻은 아닙니다.** 신뢰하는 영상·설정 파일을 사용하고 Python과 브라우저를 최신 상태로 유지하세요. 이 서버는 개인 로컬 실행용이므로 포트 포워딩·터널링·주소 변경으로 외부에 공개하지 마세요. Python의 [`http.server` 설명](https://docs.python.org/3/library/http.server.html)도 공개 운영 서버와 기본 파일 제공을 구분합니다. 자세한 범위와 제보 방법은 [SECURITY.md](SECURITY.md)를 참고하세요.

## 제한사항과 문제 해결

- 2–64프레임, 최대 2048px 처리이며 원본보다 확대 추출하지 않습니다. 메모리·시트 크기 제한이 추가로 적용됩니다. 큰 작업은 RAM을 많이 쓸 수 있으니 느려지면 해상도·프레임 수를 줄이세요.
- 자동 흔들림 보정·프레임 보간·AI 배경 제거·영상 생성 API는 없습니다. 캐릭터에 배경색이 있거나 머리카락·모션 블러·그림자가 복잡하면 원본 개선이나 추가 보정이 필요할 수 있습니다.
- MP4/MOV는 파일 포맷이며 재생 코덱을 보장하지 않습니다. 열리지 않으면 브라우저 지원 코덱으로 변환하세요. 변환 프로그램은 포함하지 않습니다.
- 움직임이 비슷하게 보이면 서로 다른 원본 프레임 수와 추출 간격을 확인하세요. 너무 짧은 구간에서 많이 뽑으면 같은 장면을 반복하고, 긴 구간에서 적게 뽑으면 중간 자세를 놓칠 수 있습니다.
- Python을 찾지 못하면 설치 후 터미널을 다시 여세요. 포트 오류는 `--port 8900`, 브라우저 자동 열기 실패는 출력된 주소 복사로 해결할 수 있습니다. 업데이트 후 Windows는 Ctrl+F5, macOS는 Command+Shift+R로 새로고침하세요.

## 개발과 검사

사용할 때 빌드나 `pip`/`npm install`은 필요하지 않습니다. Python 검사는 표준 라이브러리만 사용하고 JavaScript 검사는 Node.js 22 이상이 필요합니다.

```sh
# Windows에서는 python3 대신 py -3 또는 python
python3 -m unittest discover -s tests -p "test_*.py"
node --test tests/core.test.mjs tests/i18n.test.mjs
npm run check
```

서버를 실행한 상태에서 `node tests/browser-check.mjs http://127.0.0.1:8765`로 선택적인 Chrome 통합 검사를 실행합니다. 검사 중 브라우저에서 도형 걷기 WebM을 만들므로 개인 영상이나 외부 그림이 필요하지 않습니다. Chrome 경로가 다르면 `SPRITE_TEST_BROWSER`를 지정하세요. 임시 다운로드는 Git에서 제외한 `.qa/`에 저장합니다.
